# Presentación personal | Mi primera página web

Página web personal desarrollada como ejercicio práctico durante mi formación en el programa de **Dev.f, Bécalos y Traxión**, como parte de un curso de desarrollo de software.

El proyecto consiste en crear una página web para presentar información personal, intereses y medios de contacto, aplicando los fundamentos del desarrollo web.

## ✨ Características

- **Inicio:** presentación personal y fotografía.
- **Sobre mí:** descripción personal e intereses.
- **Pasatiempos:** lista de actividades y aficiones.
- **Redes sociales:** enlaces a GitHub y LinkedIn.
- **Contacto:** formulario con campos para nombre, correo electrónico y mensaje.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3

## 📚 Aprendizajes

Durante el desarrollo de este ejercicio practiqué:

- Estructuración de páginas web con HTML.
- Uso de etiquetas semánticas y elementos HTML.
- Organización de contenido mediante secciones y listas.
- Creación de formularios.
- Aplicación de estilos con CSS.
- Integración de imágenes y enlaces externos.
